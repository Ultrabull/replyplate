What am I actually looking at?

This restaurant does not exist. The page is a demo, built so a restaurant owner can see the ReplyPlate chat helper working on a real-looking site rather than being told about it.

The chat contains no AI and makes no network requests. It can only repeat answers the owner wrote, so it can never guess at an allergy question. Ordering takes no money: the customer taps items and sends the order from their own phone, which is also what verifies them.
